Track time. See what you earn.

TickBill is a free Chrome extension for freelancers. Start a timer in one click, set an hourly rate per client, and export timesheets for invoicing.

Coming soon to the Chrome Web Store.

Features

  • One-click start and stop from the toolbar
  • Live earnings at each client's hourly rate
  • Weekly hours and earnings per client
  • CSV export for invoices and spreadsheets
  • No account. Your data never leaves your browser
