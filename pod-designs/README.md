# Print-on-demand designs and stock assets

- `pod-designs/build.py` draws 24 original shirt/sticker/mug designs (4500x5400 transparent PNG, light and dark ink).
- `pod-designs/listings.py` writes Redbubble/Teepublic listings, the Adobe Stock metadata CSV and stock pack text.
- `stock-assets/icons.py` (48 line icons), `stock-assets/patterns.py` (12 seamless patterns, 12 gradient backgrounds), `stock-assets/package.py` (covers and zips).

Fonts are SIL Open Font License from Google Fonts (Anton, Bebas Neue, Pacifico, Lobster, Shrikhand, Archivo Black...), which allows commercial use in artwork.
Outputs are not committed; they live in the project's shared files (income/pod, income/stock).
