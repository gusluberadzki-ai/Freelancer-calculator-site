FOLIO: FREELANCER PORTFOLIO TEMPLATE
====================================

Thanks for your purchase! This is a single-page portfolio site: one HTML file, no build tools, no frameworks.

EDIT IN 10 MINUTES
1. Open index.html in any text editor (VS Code, Notepad, TextEdit).
2. Search for "EDIT:" to find every place you should change.
3. Replace the name, text, services, prices, testimonials and email.
4. Put your images in the images/ folder and follow the comments to add them.
5. Change the brand colour: edit --accent near the top of the file.

PUBLISH FOR FREE (pick one)
- Netlify Drop: go to app.netlify.com/drop and drag this folder onto the page.
- GitHub Pages: upload the files to a public repo, then Settings > Pages.
- Cloudflare Pages: create a project and upload the folder.

FEATURES
- Responsive, mobile-first layout
- Automatic dark mode
- Smooth scroll-in animations (respects reduced-motion settings)
- Sections: hero, work, services with prices, testimonials, about, contact
- Loads fast: one file, one font
