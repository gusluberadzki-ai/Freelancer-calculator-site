Free QR code generator

Make a QR code for a link, text, Wi-Fi, email or SMS. No sign-up, no tracking, and the code never expires.

Static QR codes that never expire

Many "free" QR code sites create a dynamic code that redirects through their server, then switch it off unless you pay. This generator makes a static code: the link or text is stored in the pattern itself, so it keeps working forever with no subscription.

Tips for a QR code that scans

  • Keep strong contrast: a dark code on a light background works best.
  • Print it at least 2 cm (about 0.8 in) wide.
  • Use higher error correction if you'll print it on something that might get scratched.
  • Always test it with your phone camera before printing.
