What is Base64?

Base64 turns any data into plain letters, numbers and a few symbols so it can travel safely through systems that only handle text, such as email or URLs. It's an encoding, not encryption: anyone can decode it.

Does it support emoji and accents?

Yes. Text is converted to UTF-8 before encoding.
