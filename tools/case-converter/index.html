When to use each case

  • Title Case for headings and titles
  • Sentence case for normal text and most UI labels
  • camelCase, snake_case, kebab-case for code, file names and URLs

Frequently asked questions

Does Title Case keep small words lowercase?

Yes. Words like 'a', 'and', 'of' and 'the' stay lowercase unless they start the title.
