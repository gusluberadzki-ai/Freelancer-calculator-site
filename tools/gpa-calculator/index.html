How GPA is calculated

Each letter grade has a point value (A = 4.0, B = 3.0 and so on). Multiply each course's points by its credit hours, add them up, and divide by the total credits.

Frequently asked questions

Does my school use the same scale?

Most US schools use this 4.0 scale, but some give A+ 4.3 or use different plus/minus values. Check your school's handbook.
