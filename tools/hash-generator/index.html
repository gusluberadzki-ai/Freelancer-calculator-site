What is a hash?

A hash function turns any input into a fixed-length fingerprint. The same input always gives the same hash, and a tiny change gives a completely different one. Hashes are used to check file integrity and store passwords (with salting).

Frequently asked questions

Can a hash be reversed?

No. You can only check a guess by hashing it and comparing.

Is SHA-1 safe?

Not for security. Use SHA-256 or stronger.
