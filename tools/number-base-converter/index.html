How bases work

Decimal uses ten digits, binary uses two (0 and 1), octal uses eight and hexadecimal uses sixteen (0–9 then A–F). One hex digit is exactly four binary digits, which is why programmers use hex.

Does it handle big numbers?

Yes. It uses arbitrary-precision integers, so there's no size limit.
