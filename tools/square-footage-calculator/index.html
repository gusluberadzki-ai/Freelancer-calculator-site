How to measure a room

Measure the longest length and width of the floor, then multiply them. For an L-shaped room, split it into two rectangles, work out each one and add them together. When buying flooring, add about 10% for cuts and waste.

Frequently asked questions

How many square feet in a square metre?

One square metre is 10.764 square feet.

How do I measure an irregular room?

Divide it into rectangles, calculate each one separately and add the areas together.
