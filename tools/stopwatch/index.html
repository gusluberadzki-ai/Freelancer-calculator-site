    About this stopwatch

    It uses your browser's high-resolution timer, so it stays accurate even if the display updates slowly. Lap times show the split for each lap and the total time in brackets.

    Frequently asked questions

    Does it keep running if I switch tabs?

    Yes. Time is measured from the start moment, so it stays correct even if the tab is in the background.
