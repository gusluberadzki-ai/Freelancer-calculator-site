How text becomes binary

Each character is turned into one or more bytes using UTF-8, and each byte is written as eight binary digits. Plain English letters take one byte each; accented letters and emoji take two to four.

Frequently asked questions

What does 01001000 mean?

It's 72 in decimal, which is the letter H.
