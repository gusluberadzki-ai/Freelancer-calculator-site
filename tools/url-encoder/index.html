URL encoder

Percent-encode text for URLs, or decode an encoded URL.

–

Which mode?

Use query value to encode a single parameter value: it encodes &, = and / too. Use full URL to make a whole address safe while keeping its structure.

Frequently asked questions

Why are spaces %20 and not +?

Both mean a space in query strings. %20 is safe everywhere, so the encoder uses it; the decoder accepts both.
