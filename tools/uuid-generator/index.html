What is a UUID?

A UUID is a 128-bit identifier. Version 4 UUIDs are random, with so many possible values that collisions are practically impossible, so they're safe to use as database keys without coordination.

Frequently asked questions

Are these secure?

Is a GUID the same thing?

Yes. GUID is Microsoft's name for a UUID.
